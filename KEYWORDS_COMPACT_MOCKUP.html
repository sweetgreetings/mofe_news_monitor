검색어 화면 — 촘촘하게 · 설명 줄이기

등록된 그룹 6개(data/settings.json 그대로)로 그렸어요. 폭은 실제와 같은 800px이고, 창이 좁으면 비율대로 줄어듭니다. 칩을 누르면 켜고 끄기, 정기 체크도 눌러볼 수 있어요.

1
칩·칸 위아래 여백
  • 키워드 칩 높이 32 → 25px (글자 .9 → .86rem, 위아래 여백 7 → 4px). 입력 칩도 같은 높이로.
  • 그룹명 칸 34 → 27px, 카드 안쪽 여백 14·16 → 10·12px.
  • 카드 아래 세 줄(키워드 수 / 검색 방식 / 정기 체크)을 한 줄로 — 키워드 수는 머리줄 오른쪽 6/10, 검색 방식은 작은 두 칸 버튼(「검색 방식」 글자는 툴팁).
2
개요·설명 — 네 덩어리 → 두 줄
  • 빨간 「🔴 실시간 현황」 칩은 뺐어요. 실시간은 "켜 둔 그룹 전부"라 따로 이름표를 붙일 대상이 아니에요. 대신 문장 안에 카드에 실제로 있는 정기 체크 모양을 그대로 넣어, 설명과 카드가 이어 읽히게 했어요.
  • 「최대 8개·10개·최소 1개」 → 뺌. 카드마다 6/10이 있고, 8개가 차면 추가 버튼이 잠기고, 최소 조건은 저장 바가 막으면서 이유를 말해요. 「(그룹 간 OR)」도 용어라 뺌.
  • 「저장하면 실시간엔 바로, 정기는 다음 회차부터」 → 저장 바 안내로 옮김. 고친 게 있을 때만 보이고, 읽는 자리와 누르는 자리가 같아져요(맨 아래 저장 바 모형 참고).
3
정기 스크랩 체크 — 70자 → 5자
  • 「정기 스크랩(예정된 회차)에도 포함 — 실시간 기사 현황에는 늘 나옵니다. 꺼두면 …」 → 「정기 스크랩」. 나머지는 마우스를 올리면 툴팁으로.
  • 켜면 글자가 진해져요 — 카드 여섯 장을 훑기만 해도 어느 그룹이 정기에 들어가는지 글자 무게로 보입니다.
+
덤 — 그룹명 칸이 회색 상자인 건 원래 의도가 아니에요
  • 코드는 「평소 투명, 올리면 테두리」로 적혀 있는데, 공용 input[type=text](회색 배경) 규칙이 명시도가 더 높아서 이기고 있어요. 시안은 원래 의도대로 그렸어요 — 이름이 입력칸이 아니라 카드 제목처럼 읽힙니다.
