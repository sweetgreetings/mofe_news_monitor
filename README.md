# 재정경제부 언론 모니터링

재정경제부 언론 담당자 한 명이 **자기 컴퓨터에서만** 쓰는 뉴스 모니터링 도구입니다.
정해진 시각마다 네이버 뉴스를 검색해 기사를 모으고, 소제목별로 묶어 브라우저 화면에
보여줍니다. 담당자는 화면에서 기사를 숨기거나 순서를 다듬은 뒤 텍스트로 복사하거나
텔레그램·이메일로 보냅니다.

- 소제목 묶기만 Claude API(Haiku)를 씁니다. API 키가 없거나 호출이 실패하면 규칙 기반
  (단어 빈도)으로 자동으로 넘어가므로 키 없이도 앱 전체가 동작합니다.
- 요약·워드클라우드 등 나머지는 전부 규칙 기반이라 비용이 들지 않습니다.

> 개발자·Claude Code용 규칙은 [CLAUDE.md](CLAUDE.md), 변경 경위는 [HISTORY.md](HISTORY.md),
> 기획서는 [PRD.md](PRD.md)에 있습니다.

## 주요 기능

- **자동 수집**: 설정한 회차 시간창마다 수집합니다. 앱이 꺼져 있던 사이 놓친 오늘 회차는
  켜지는 대로 오래된 것부터 채웁니다. 실패하면 5분 간격으로 3번까지 다시 시도합니다.
- **소제목 분류**: 쟁점별로 최대 15개. 초안에서 회차당 한 번 자동으로 묶고, 그 뒤로는
  담당자가 누를 때만 AI를 부릅니다(「AI 기사 배정」·「AI 기사 나누기」·「AI 모든 기사 재분류」).
- **큐레이션**: 숨기기(7일 안에 휴지통에서 되살림), ↑↓ 순서, 다른 소제목으로 옮기기,
  소제목 이름 바꾸기·만들기, ↩ 되돌리기. 담당자가 정한 순서가 언론사 순서보다 항상 우선합니다.
- **출력**: `ㅇ (언론사) 제목` + URL 형식으로 복사·`.txt`·엑셀(8열). 형식은 설정에서 바꿉니다.
- **발송**: 확정본의 (발송) 버튼, 또는 설정한 유예시간(기본 5분) 뒤 자동발송.
  텔레그램·이메일 모두 여러 명에게 따로 보냅니다.
- **[단독]·[속보] 알림**: 말머리가 붙은 기사를 텔레그램으로 바로 알립니다.
- **라벨**: 기사에 자유 태그를 붙여 나중에 모아 봅니다.

## 설치

```bash
git clone https://github.com/sweetgreetings/news-scrap.git ~/press-monitor
cd ~/press-monitor
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> 자동 실행을 쓸 거라면 폴더를 **데스크탑·서류·다운로드 밖**(예: `~/press-monitor`)에 두세요.
> macOS가 그 세 폴더를 백그라운드 프로그램으로부터 막습니다.

### API 키

네이버 검색 API 키는 **필수**, 나머지는 선택입니다. 앱을 켠 뒤 설정 화면(`/naver`, `/llm`)에서
등록하거나, 프로젝트 루트의 `.env`에 넣습니다([.env.example](.env.example) 참고). 둘 다 있으면
설정 화면 값이 우선합니다.

| 항목 | 어디서 받나 |
|---|---|
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | [네이버 개발자센터](https://developers.naver.com) — 애플리케이션 등록, "검색" API 사용 |
| `ANTHROPIC_API_KEY` (선택) | [Anthropic Console](https://console.anthropic.com) |
| `TELEGRAM_BOT_TOKEN` (선택) | [@BotFather](https://t.me/BotFather)에서 봇 생성. 설정 › 연동 › 텔레그램 발송 계정에서 넣어도 된다 |
| `EMAIL_SMTP_HOST` / `EMAIL_SMTP_PORT` / `EMAIL_SENDER_ADDRESS` / `EMAIL_SENDER_PASSWORD` (선택) | 메일 서비스의 SMTP 정보. 비밀번호는 2단계 인증 후 발급하는 **앱 비밀번호**. 설정 › 연동 › 이메일 발송 계정(네이버·Gmail)에서 넣어도 된다 |

텔레그램·이메일 **받는 사람**은 `.env`가 아니라 설정 화면(`/telegram`, `/email`)에서 등록합니다.

## 실행

```bash
python3 main.py
```

브라우저가 홈 화면을 엽니다. 앱이 이미 켜져 있으면 새로 띄우지 않고 그 화면만 엽니다.
종료는 터미널에서 `Ctrl+C`.

### 로그인할 때 자동으로 켜기 (macOS)

```bash
bash autostart/install.sh
```

해제는 `bash autostart/uninstall.sh`. 폴더를 옮기면 새 위치에서 다시 설치합니다.
자세한 내용은 [autostart/README.md](autostart/README.md).

## 알려진 한계

- **인터넷에 올리면 안 됩니다.** 로그인·권한이 없고 로컬 파일에 저장하는 구조라, 외부에
  노출하면 누구나 설정을 바꾸고 기사를 지울 수 있습니다. 서버리스 환경에서도 돌지 않습니다.
- 컴퓨터가 잠들어 있거나 꺼져 있는 동안은 수집하지 못하고, 어제 이전 회차는 채울 수 없습니다
  (네이버 검색 API에 기간 지정이 없고 키워드당 최신 1000건까지만 줍니다).
- 큐레이션은 가장 최근 회차(확정본)와 초안에서만 됩니다. 정기 보관함은 읽기 전용입니다(라벨·삭제 제외).
- 소제목 분류는 담당자가 검토하는 것을 전제로 합니다.
- 여러 명이 함께 쓰는 형태는 지원하지 않습니다([MULTIUSER_ROLLOUT_CHECKLIST.md](MULTIUSER_ROLLOUT_CHECKLIST.md)).

- 데이터베이스 없음 — JSON 파일
