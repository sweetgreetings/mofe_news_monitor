# figma/ — 피그마로 불러오는 화면 SVG

실제로 돌고 있는 앱 화면(`127.0.0.1:8765`)을 **1440px 뷰포트**에서 그대로 뜬 SVG다.
목업이 아니라 **현재 구현된 화면 그대로**이며, 앱 화면이 바뀌면 다시 뽑아야 한다.

## 피그마로 가져오기

1. 피그마 파일을 연다.
2. 이 폴더의 `.svg` 파일을 캔버스에 **끌어다 놓는다** (여러 개 한 번에 가능).
3. 각 파일이 프레임 하나로 들어온다. 레이어 패널에 화면 구역별 그룹이 잡혀 있다.

`File > Import` 로도 되지만 드래그가 더 간단하다.

### 들어오는 것 / 안 들어오는 것

| 들어옴 | 안 들어옴 |
|---|---|
| 배경·테두리·모서리 둥글기 | `box-shadow` (그림자) |
| **편집 가능한 텍스트 레이어** (색·크기·굵기 유지) | 오토레이아웃 / 컴포넌트 (그냥 그룹으로 들어옴) |
| 아이콘 (인라인 SVG를 벡터 그대로 이식) | `:hover` 등 상태 변화 |
| `<select>` 안 표시 텍스트, 로고 이미지 | 접혀 있는 기사 본문 (화면에서 안 보이므로 제외) |

**폰트**: 원본은 `Pretendard`다. 피그마에 설치돼 있지 않으면 대체 폰트로 열리고
줄 간격이 살짝 달라 보일 수 있다. 정확히 맞추려면 Pretendard를 설치하고 열면 된다.

## 다시 뽑는 법

앱이 켜져 있어야 한다(`python3 main.py`). 화면을 고친 뒤 다시 뽑으려면
Claude Code에게 "figma SVG 다시 뽑아줘"라고 하면 된다 — DOM 지오메트리를
직접 읽어 SVG로 옮기는 추출 스크립트를 쓰며, 손으로 그리는 게 아니라
**실제 렌더링 결과를 그대로 옮기는 방식**이라 화면과 어긋나지 않는다.
