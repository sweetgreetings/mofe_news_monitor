## 3. 핵심 기능
> 처음엔 "딱 2가지만"으로 시작했다(2026-07-22). 실제로 만들면서 5개가 됐고,

### 1) 정기 모니터링 (기사 자동 스크랩) [이름 변경: 2026-08-18, 구현 완료 — "자동 스크랩" → "정기 모니터링"]
- 설명: 네이버 뉴스에서 재정경제부 관련 기사를 자동으로 스크랩하여 메모장 형식으로 변환. 흐름은 `초안` →(회차 마감) `확정본` →(다음 회차) `정기 보관함`이며 둘 다 자동이라 누를 버튼이 없다. 분류 기준은 **일자 › 시간대**
- AI가 꼭 지켜야 할 규칙:
  1. 하루 여러 회차 자동 실행 — [수정: 2026-08-18] 예전엔 "오전 9시 / 10시 30분 / 오후 1시 30분 / 4시 30분"으로 적어뒀으나, 회차 시각·개수는 담당자가 설정 화면에서 자유롭게 바꾸는 값이라 문서에 박아두면 금방 사실과 달라진다
  2. 언론사 우선순위: ① 방송사(KBS, MBC) → ② 주요 언론사(조선일보, 중앙일보, 동아일보, 한국경제, 매일경제, 서울경제, 한국일보, 머니투데이, 이데일리, 연합뉴스, 뉴시스 등) 순으로 정렬
  3. 출력 형식은 다음과 같고, 게시일자는 표시하지 않음
     ```
     ㅇ (언론사) 기사제목
     URL
     ```
  4. [수정: 2026-08-18] **기사 원문은 저장하지 않는다** — 네이버 API가 주는 요약(description)만 저장한다(문서에 "원문 전체를 저장"으로 잘못 적혀 있었다). 하이라이트도 연두색 단색이 아니라 **단어마다 다른 파스텔 5색이 순환**하며, 하이라이트 단어는 검색 키워드와 별개로 등록한다
  5. [추가: 2026-08-18] 네이버 API 자체의 **키워드당 최신 1000건** 상한이 있다. 넘으면 더 오래된 기사는 못 가져오고 결과가 조용히 잘린다(실패로도 안 잡힘) — 발생 시 로그만 남긴다

### 2) 소제목 자동 분류
- 설명: 기사 요약을 분석해 소제목으로 자동 분류하고, 키워드와 요약을 추출
- AI가 꼭 지켜야 할 규칙:
  1. 소제목 카테고리는 최대 15개 [수정: 2026-08-20, 8→15 — 재정경제위 있는 날처럼 기사 40건 넘는 회차에서 8개로는 기타에 30~75%가 몰림. HISTORY.md 참고], 기사 1건은 소제목 1개에만 배정 (한 소제목에 여러 기사 포함 가능)
  2. 요약은 3문장·**250자** 이내 [수정: 2026-08-18 — 문서에 100자로 남아 있었으나 실제 구현은 250자]
  3. 키워드는 **쉼표 나열**로 표시 [수정: 2026-08-18 — `#키워드` 형식은 2026-07-24에 폐기됨]
  4. 소제목은 **분류 도우미이지 절대적인 값이 아니다** — 비어 있거나 "미분류"인 기사가 섞여도 정상

### 3) 수시 모니터링(비정기 스크랩) [설계 확정: 2026-08-13, 구현: 2026-08-13]
- 설명: 위 두 기능은 정해진 시간대에 자동으로 도는 "정기" 스크랩이다. 이것과 별개로, 담당자가 특정 사안이 생겼을 때(상위자 지시·현안 발생) 사안명·검색어·시간대를 그때그때 직접 지정해 한 번에 모으는 기능. 자세한 규칙은 [ADHOC_DESIGN.md](../ADHOC_DESIGN.md) 참고
- AI가 꼭 지켜야 할 규칙:
  1. 자동 스케줄 없음 — 담당자가 사안명·검색어(최대 5개)·시작~종료 시각을 입력하고 [수집]을 눌러야 실행됨. 정기 키워드·정기 저장소는 전혀 건드리지 않음(완전히 분리된 별도 데이터)
  2. 발송 기능 없음 — 복사·다운로드(.txt)만 제공
  3. [수정: 2026-08-18, 구현 완료] 흐름과 이름을 `새 수집` → `수집 결과` → `수시 보관함`으로 통일. 분류 기준은 **사안 › 일자**. 보관 기간은 정기와 똑같이 **1년**(예전엔 "제한 없음"이었으나, 두 보관함 정책이 다르면 담당자가 따로 기억해야 함)
  4. [추가: 2026-08-18, 구현 완료] **자정에 카드가 수시 보관함으로 자동으로 넘어간다** — 아무것도 안 눌러도 된다. ([지금 넘기기] 버튼은 **아직 미구현** — 자정 자동 이월만 동작한다.) 보관함에 들어간 뒤에도 계속 고칠 수 있다
  5. [추가: 2026-08-18, 구현 완료] 같은 사안을 하루 여러 번 = **카드 1개 + 재수집**(종료 시각은 현재까지 자동 연장), 다른 사안 = **카드 별개**. [수정: 2026-08-20] 재수집은 병합이 아니라 **교체**다(단 기사를 지우진 않아 조건을 되돌리면 정리도 돌아온다). [수집 결과]는 오늘 카드 중 최근 것을 바로 열고 위에 사안명 탭을 얹는다

### 4) 라벨 [설계 확정: 2026-08-18, 구현 완료]
- 설명: 기사 한 건에 담당자가 직접 붙이는 자유 입력 태그(블로그 태그에 가까움). 소제목이 "이 회차에서 어느 묶음이었나"라면, 라벨은 "회차와 상관없이 나중에 꺼내볼 것"이라 회차를 가로지른다
- AI가 꼭 지켜야 할 규칙:
  1. 담당자가 직접 입력, 기사당 **여러 개** 가능, AI는 붙이지 않음
  2. **URL 기준 전역** — 정기에서 붙인 라벨이 수시에서도 보임
  3. **보고서 텍스트에는 절대 안 나감** — 화면과 내보내기 파일에만
  4. 입력할 때 이미 쓴 라벨 목록을 함께 보여줌(오타로 갈라지는 것 방지)
  5. 정기·수시를 가로지르는 **라벨 보관함** 화면에서 모아 봄
  6. **라벨 붙은 기사는 1년 자동 삭제에서 예외** — 라벨을 붙일 때 기사 정보(스크랩일자·종료시간·발행일·언론사·제목·URL·소제목 7개)를 함께 복사해 둠. 제목은 나중에 교정되면 최신값으로 덧씌워 보여줌
  7. **라벨 붙이는 화면은 확정본·초안·수집 결과 세 곳** — 실시간에는 안 둠(필터 없이 날 것 그대로 훑는 화면이라 성격이 다르고, 이미 있는 "📌 담아두기"와 뜻이 겹쳐 보임)

### 5) 데이터 내보내기 [설계 확정: 2026-08-18, 구현 완료]
- 설명: 보관된 기사를 표 파일로 뽑아 엑셀에서 가공. 기존 복사/.txt(보고서 문장)와 달리 이쪽은 **데이터**
- AI가 꼭 지켜야 할 규칙:
  1. 뽑는 곳은 **확정본 · 정기 보관함 · 수집 결과 · 수시 보관함 · 라벨 보관함** 다섯 군데(초안만 제외 — 곧 자동으로 확정본이 되므로)
  2. **항상 "지금 화면에 보이는 것"만 뽑는다** — 별도 기간/범위 선택 UI 없음
  3. 열 8개: `스크랩일자 | 스크랩종료시간 | 발행일 발행시간 | 언론사명 | 기사제목 | URL | 소제목 | 라벨명`
  4. 라벨이 여러 개면 한 칸에 `세제, 보고서`로 합침
  5. **파일 형식은 `.xlsx`로 확정**(CSV는 엑셀이 `-`/`=` 시작 셀을 수식으로 오인식하는 문제가 있어 제외)
  6. **파일명은 `날짜_종류_구분`으로 통일**(예: `2026-08-18_정기_11시.xlsx`) — 기존 `.txt` 파일명도 이번에 함께 이 규칙으로 바꿈
