수시 원본 · 검색어 편집을 새 수집과 같은 모양으로

검색어 칸 두 개(검색어 / 꼭 포함할 검색어)를 칸 하나 + 「하나라도 / 모두」 라디오로 바꿔요. 새 수집 화면의 그 라디오와 같은 문구·같은 색·같은 상한(하나라도 5개, 모두 3개)이에요. 수집 시간 칸과 「다시 불러오기」는 그대로예요.

같은 단어가 두 칸에 다 찍혀요. 새 수집에서 「모두」를 고른 사람이 무엇을 골랐는지 거꾸로 해석해야 해요.

바꾼 뒤 칸 하나 + 라디오 (눌러서 써 보세요)
시작 상태:
… 11:33 ~ 14:35 14:33 0건 · 14:35 +0건 닫기
~
지금 조건으로 목록을 새로 만들어요
  • 검색어 칸 아래 설명 줄이 라디오로 바뀌어요. 지금의 「추가하면 기사가 늘어나요 / 줄어들어요」 안내는 고른 쪽 아래 회색 줄로 옮겨요.
  • 칩 ×·+ 추가·라디오 모두 누르는 즉시 반영돼요(지금 칩과 같은 방식 — 다시 수집하지 않고 모아 둔 결과에서 거르고, 되돌리기 ↩ 대상). 「다시 불러오기」는 시간을 바꿀 때만 필요해요.
  • 검색어가 1개면 라디오가 흐려져요 — 두 선택지가 같은 뜻이라서(새 수집과 같음).
  • 「모두」는 3개까지. 4개 이상일 때는 「모두」를 못 누르고 몇 개를 빼야 하는지 앰버로 알려 줘요. 「모두」 상태에선 칸이 3개에서 잠겨요.
  • 머리 칩: 하나라도면 지금처럼 돈까스 0 · 음식 0, 모두면 단어를 청록 돈까스 + 음식으로 한 번만 써요(두 줄 중복 없음). 모두일 때 키워드별 건수는 빼요 — 남은 기사는 전부 두 단어를 다 갖고 있어서 숫자가 모두 같아요.
  • 「모두」에서 한 단어라도 네이버 1,000건 상한에 걸리면 지금처럼 적용을 거부하고 오류 배너를 띄워요.
