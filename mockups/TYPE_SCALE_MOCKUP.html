글자 크기 시안

지금 앱 CSS에 글자 크기가 38가지(0.61~1.4rem, 아이콘 크기 빼고) 쓰인다. 여섯 단계로 줄인다. 예시는 모두 지금 떠 있는 앱의 실제 CSS·마크업이고, 「제안」은 글자 크기만 아래 단계로 옮겼다(색·모양·간격은 그대로).

2. 화면 제목이 화면마다 다르다

같은 자리(화면 맨 위 제목)인데 8가지 크기. 모두 --fs-xl 1.3rem로.

추이언론 모니터링 14시 기준1.35rem→1.3rem
초안언론 모니터링 14시 기준1.3rem→1.3rem
설정 · 보관함언론 모니터링 14시 기준1.3rem→1.3rem

수시 원본·확정본 머리줄언론 모니터링 14시 기준1.1rem→1.3rem
라벨 관리언론 모니터링 14시 기준1.05rem→1.3rem
홈 (로고 옆)언론 모니터링 14시 기준1.05rem→그대로 (질문 1)

3. 지금 → 제안

위가 지금, 아래가 제안. 기사 행처럼 이미 단계에 가까운 곳은 거의 안 바뀐다.

확정본 머리 · 툴바정기 확정본 (초안도 같은 코드)
지금
제안

제목 1.4 → 1.3(초안·설정·보관함과 같게). 칩 0.78 → 0.8. 툴바 버튼·copy 0.9 → 0.88.

소제목 · 기사 행정기 확정본
지금
제안

소제목 1.1 그대로(lg). 기사 제목 1rem 그대로. 메타 줄 0.8 그대로, 행 드롭다운 0.78 → 0.8. 눈에 띄는 변화가 거의 없어야 정상 — 기사 행은 이미 단계 값에 가깝다.

배너늦게 들어온 기사
지금
제안

0.86 → 0.88, 건수 칩 0.78 → 0.8.

4. 단계 밖에 두는 것 (예외)

  • 아이콘 크기 — ↩·🗑·목차·⋯·×·🏷처럼 font-size로 아이콘 크기를 정하는 곳(82곳). 글자가 아니라서 따로 둔다.
  • 제목에 붙는 언론사 0.86em — 제목 크기에 비례하는 값이라 그대로(8곳의 em 값).
  • 홈 워드클라우드 5단계(1.30~0.76rem) — 크기 자체가 정보(많이 나온 단어)라서.
  • 로딩 아이콘(2.1rem) · 대기 화면 큰 아이콘(2rem) · 손글씨 캡션.

5. 값을 두는 곳

  • 모양 토큰과 같은 방식: app/config.py에 FONT_XS~FONT_XL, CSS엔 font-size: var(--fs-md). 정의는 SHAPE_TOKENS_CSS에 함께 넣는다.
  • 굵기는 이번엔 그대로(지금도 400·500·600·700 네 가지로 거의 정리돼 있다).

6. 정해 주실 것

  1. 홈 머리 제목(로고 옆 「AI 뉴스 모니터링」 1.05rem)은 예전에 작게 정한 자리예요. 예외로 그대로 둘까요(추천), 다른 화면처럼 1.3으로 올릴까요?
  2. 수시 원본·확정본 머리줄을 1.1 → 1.3으로 올려 정기 확정본 제목과 같게 할까요? (추천: 올린다 — 같은 역할의 줄이다)
  3. 펼친 기사 요약은 지금 0.95rem(제목과 거의 같음)이에요. 0.88로 한 단계 낮춰 제목과 구별할까요(추천), 제목과 같은 1.0으로 둘까요?
