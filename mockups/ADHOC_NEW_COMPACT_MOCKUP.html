새 수집 화면 정리 시안

바뀌는 것
  • 검색 방식 두 줄 → 검색어 칸 오른쪽 [하나라도 | 모두] 한 칸. 설명 문장은 버튼 이름이 대신하고, 「모두」 예시·상한 경고만 필요할 때 한 줄로 뜬다.
  • 빠른 선택 칩을 시간 입력 옆 같은 줄로. 「0시 ~ 지금」은 옆 「지금」 버튼과 말이 겹쳐 0시부터로.
  • 체크 세 개를 한 줄로, 이름표 「이 회차에만 적용」은 거르기로 (「회차」는 정기 말이다). 문구도 짧게.
  • 「수집」 버튼은 맨 아래 오른쪽 — 거르기까지 고른 뒤 누르는 순서대로.
  • 제목·부제를 한 줄로(아래 「지난 수집」 머리와 같은 모양). 「검색어는 최대 5개」는 칸 안 0 / 5가 이미 말해서 뺀다.
  • 칸 높이를 36px로 통일(지금은 사안 select가 옆 입력칸보다 낮다). 줄 간격 14 → 9px.
